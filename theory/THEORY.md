# 递归自我模型涌现假说

**Recursive Self Model Emergence Hypothesis (RSMEH)**

> **状态：v0.1 — 假说，不是理论。**
> 等实验跑出来（见 `experiments/PROTOCOL.md`），再升级为 **Recursive Self Model Emergence Theory**。
> 本文件是哲学与形式化的完整版；学术版正文见 `paper/main.md`。

---

## 0. 一句话

生命最初预测世界；当世界模型无法解释持续存在的误差时，系统开始预测自己；当这个关于自己的模型本身成为预测对象，「我」便从模型中涌现。

> Life begins by modeling the world. When the world model fails to explain persistent errors, the system begins modeling itself. When the model of itself becomes an object of its own prediction, the "I" emerges.

---

## 1. 核心问题：一个发生学缺口

预测系统（生命或 AI）能建立关于环境的模型。这一点已被大量理论解释：

| 已有概念 | 它解释了 |
|---|---|
| 世界模型 World Model | 如何压缩并预测环境 |
| 身体模型 Body Model | 如何把自身身体当作可预测对象 |
| 行动模型 Agency Model | 如何区分"我的行动导致的改变"与"世界自己发生的改变" |
| 自我模型 Self Model | 如何把自身状态纳入预测以提升控制 |

但这里缺一个**发生学解释（genetic explanation）**：

> 一个原本**没有**「我」这个变量的系统，在什么条件下会**自然产生**「我」这个变量？

现有理论大多回答「自我模型是什么、有什么用」，很少回答「自我模型**为什么必须出现**」。RSMEH 只盯这个问题。

### 1.1 两类问题的分工（重要）

- **构成性问题**（Metzinger 等）：自我模型**如何**变成主观体验？（主观性从何而来）
- **发生学问题**（本假说）：自我模型**为什么首先出现**？为什么不是「只有世界模型」的系统？

RSMEH 明确**不声称**解决意识难题（hard problem）。它只处理「我」这个变量在**认知架构中的起源**，并把这件事操作化到可测量（第 8 节）。

## 2. 定义

为了让假说可证伪，每个概念都给出**操作化判据**（能被实验测到的东西）。

### 2.1 模型 Model
系统对外部或内部状态的**压缩预测结构**。判据：该结构能降低对未来输入的预测误差（不是存储数据，而是压缩）。

### 2.2 自我模型 Self Model
系统对**自身状态、行为与未来状态**的预测模型。
例：机械臂 `Arm Position → Movement Prediction → Correction`。

**判据（可测）**：存在一个内部变量 $s$，它（i）对系统自身的未来状态/行动有预测力，（ii）持续存在，（iii）被干预时行为随之改变。

> **自我模型 ≠ 自我意识。** 一台伺服电机有自我模型（它的关节模型），没有「我」。

### 2.3 自我意识 Self Awareness
不是「系统拥有关于自己的数据」，而是**系统把自身作为观察对象**：

```
I observe world
      ↓
I observe myself observing world
```

判据：系统的内部状态中出现了**关于"自己的建模过程"的建模**（二阶），且该二阶结构被用于预测。

### 2.4 递归自我模型 Recursive Self Model
本假说的核心概念。三级递进：

$$M(\text{World}) \;\rightarrow\; M(\text{World}, \text{Self}) \;\rightarrow\; M(\text{World}, \text{Self}, M)$$

第三级的意思是：**模型开始模拟产生模型的过程本身**。「我」在这个位置上出现——不是作为被建模的对象之一，而是作为**建模行为本身的指称**。

## 3. 核心假说：不可归约预测误差 → 归因压力

### 3.1 传统图景

```
Prediction Error  →  Update Model
```

误差只是学习信号；模型改就是了。

### 3.2 本假说关注的是一种特殊误差

**不可归约预测误差（Irreducible / Unresolvable Prediction Error, UPE）**，需同时满足：

1. 系统已拥有较完善的环境模型；
2. 预测失败**持续存在**（不是收敛前的暂态）；
3. 增加/细化**外部变量**无法消除它；
4. 但系统的**自身状态或行动与该误差存在稳定关系**。

条件 3 与 4 必须**同时**成立。只有 3 是「世界的锅」（外部噪声）；只有 4 是「可以靠行动修正的误差」。两者同时成立时，误差既改不掉、又不属于世界——它在结构上「无处安放」。

### 3.3 归因压力 Attribution Pressure

```
Why is prediction wrong?
        ↓
Maybe the model is incomplete.
        ↓
Maybe the predictor itself must enter the model.
```

### 3.4 竞争性解释（让假说可被证伪的关键）

面对不可归约误差，系统至少有 5 种可能反应，RSMEH 只赌其中一种：

| # | 反应 | 结果 |
|---|---|---|
| a | 扭曲世界模型（过拟合噪声） | 泛化变差 |
| b | 扭曲感知（压低精度权重） | 误差被忽略，但预测力下降 |
| c | 归因给外部（"世界就是有随机性"） | 稳定但不再进步（**这就是「世界模型的锅」情形，本假说预测它不会逼出自我模型**） |
| d | 提高探索/行动以收集信息 | 若误差可行动消除，则属可行动误差，非 UPE |
| e | **把自身纳入模型（自归因）** | 误差重新变得可解释 → RSMEH 声称的路径 |

**RSMEH 的可证伪断言**：在 UPE（第 3.2 节四条件）下，路径 (e) 在长期预测效率上优于 (a)(b)(c)。

这是整个假说最脆的一环，也是最好的攻击点：只要能构造出反例系统，它在 UPE 下长期使用 (a)(b)(c) 反而更省——假说就受伤。

## 4. 涌现过程：从反应到「我」

**先声明**：以下 Stage 0–5 是**功能依赖链**（后面的阶段在功能上需要前面的阶段），**不是**进化史上的时间表，也不声称每个生物都按顺序走完。

| Stage | 名称 | 结构 | 「我」 |
|---|---|---|---|
| 0 | 反应系统 Reactive | `Stimulus → Response` | 无 |
| 1 | 预测系统 Predictive | `Environment → Prediction → Correction` | 无 |
| 2 | 行动模型 Agency | `My action → World change`（发现自身是原因之一） | 无（Agency ≠ Consciousness） |
| 3 | 持续误差 Persistent Error | `World Model cannot explain all outcomes` → 产生「为什么？」 | 无 |
| 4 | 自我归因 Self Attribution | 模型升级为 `World Model + Self Model` | 有变量，无主体 |
| 5 | 递归自我 Recursive Self | `I predict world → I predict myself predicting world → Who is the predictor?` | **「我」涌现** |

关键跳跃在 **Stage 4 → 5**：Stage 4 只是「系统里多了一个关于自己的变量」；Stage 5 里，这个变量**成为自身预测的对象**——自我模型被递归地折叠了一次。RSMEH 押注：**第一人称视角出现在这一步，而不是更早**。

### 4.1 Stage 4 与 Stage 5 的可测差别

- Stage 4：$s_t$ 能预测**世界**（"我的手臂在哪儿，所以结果会怎样"）。
- Stage 5：$s_t$ 能预测**$s_{t+1}$ 或系统自己的预测过程**（"我下一步会怎么想/会预测错什么"）。

后者对应实验指标 **RMG（递归建模增益）**：把「系统对自己的建模」本身当作预测目标，是否还有可提取的规律。

## 5. 自我模型 ≠「我」：三档对照

### 5.1 草履虫（或细菌）
✔ 内外区分 ✔ 状态调节 ✔ 环境适应
✘ 无证据表明拥有第一人称主体。
—— 有「自我调节」，不等于有「自我」。

### 5.2 机器人
✔ 身体模型 ✔ 动作模型 ✔ 预测模型

```
Motor Command → Expected Result → Correction
```

这是**控制系统**。它的自我模型可以做到极致精确（Hafner 等的 latent dynamics、Lipson 组的 self-modeling robot），但预测越来越准 ≠ 产生「我是谁」。这是**优化**，不是**主体**。

### 5.3 人类
```
World → Self Model → Model of Self Model → "I"
```
（这是假说所声称的结构，不是一个已被神经科学确证的机制。）

### 5.4 判据阶梯（防止拟人化自欺）

任何关于「某系统产生了自我」的主张，必须逐级过关：

| Level | 名称 | 判据 |
|---|---|---|
| 0 | 语言自指 | 系统说「我」——**不算数** |
| 1 | 有根据的自指 | 准确指称自己的状态/行动 |
| 2 | 持续自我模型 | 稳定内部表征能预测自身未来状态/行动 |
| 3 | 因果自我模型 | 干预该表征 → 行为随之改变 |
| 4 | 递归自我模型 | 系统建模自己的建模过程 |
| 5 | 主观体验 | **实验不碰，未知** |

RSMEH 的实验只瞄准 Level 1–4。Level 5 不声称。

## 6. 与既有理论的关系

### 6.1 预测加工 / 主动推理（Predictive Processing, Active Inference）
贡献：生物通过最小化预测误差维持自身（Rao & Ballard 1999；Friston 2010；Clark 2013；Hohwy 2013）。
RSMEH 的关系：**不是竞争者，而是补一个边界条件**。标准框架里误差总能通过「更新模型 / 行动 / 调整精度」被处理掉；RSMEH 关注的恰是这三条路都失效的区域——**不可行动的、外部的、且自因的误差**。此处目标函数无论如何都无法归零，系统唯一剩下的操作是**重新描述误差的来源**，而「自身」正是唯一还没进模型的那个来源。

值得注意：Friston（2018）问过「自我组织是否蕴含自我意识」；RSMEH 的问题更窄——不问蕴含，问**变量**：什么条件下必须引入一个自指变量。

### 6.2 机器人自我模型（Lipson / Bongard / Hafner）
贡献：自我模型能显著提升控制、预测与适应（Bongard, Zykov & Lipson 2006；Hafner 等 2019）。
RSMEH 的关系：这些工作证明「自我模型有用」，RSMEH 追问「自我模型**被迫**出现的条件」。二者的差别正是 Stage 4 与 Stage 5 的差别：**有用**（能预测世界）≠ **递归**（能预测自己的预测）。

### 6.3 Metzinger 的自我模型理论
贡献：解释自我模型如何产生**主观体验**（Metzinger 2003, 2009）。
RSMEH 的关系：问题方向相反且互补——
- Metzinger：Self 如何成为**体验**？
- RSMEH：Self 为什么**首先出现**？

### 6.4 其他邻接理论，以及 RSMEH 的差异点

| 理论 | 核心 | 与 RSMEH 的差别 |
|---|---|---|
| 高阶表征理论 HOT（Rosenthal 2005） | 一阶状态被高阶表征「读到」→ 意识 | HOT 不解释高阶表征**为什么必然出现**；RSMEH 给出触发条件（UPE） |
| 注意图式理论 AST（Graziano 2013；Graziano & Webb 2015） | 大脑建模自己的注意 → 报告「我在体验」 | AST 的自我模型服务于**社会认知/控制**；RSMEH 强调**误差归因**是触发源 |
| 全局工作空间 GWT（Baars 1988） | 信息全局广播 → 意识 | 讲的是**架构**，不是**起源** |
| 整合信息论 IIT（Tononi 2004） | 系统整合信息量 Φ | 度量「有多少意识」，不解释「我」的成因 |
| 自指学习（Schmidhuber 1987, 2003） | 系统可以修改/建模自己的学习算法 | 工程路线；RSMEH 问自然条件下它**被逼**出现的动力学 |
| 叙事自我（Dennett 1991；Damasio 1999） | 自我是叙事中心 | 讲内容与功能，不讲发生学条件 |
| 自由能自我（Apps & Tsakiris 2014；Seth 等） | 内感受预测编码构成自我 | 与 RSMEH 相容；RSMEH 给出「何时必须升级到递归」的判据 |
| 语言模型自我知识（Binder 等 2024） | LLM 能学会关于自己的预测 | 提供了检验 Level 1–2 的现代平台；不涉及递归（Level 4） |

### 6.5 与《意识 Bug 假说》的关系（同源不同问）

两者共享一根引信：**「我」可能不是能力，而是债务。**

| | 意识 Bug 假说 | RSMEH（本假说） |
|---|---|---|
| 追问 | 意识是否是**无法顺利执行**的副产品 | 「我」这个**变量**如何涌现，以及递归这一步 |
| 焦点 | Bug → 解释 Bug → 创造「我」 | Stage 0→5 的发生链，**特别押注 Stage 5（递归）** |
| 实验 | 自因误差 vs 外部误差对自我建模的驱动 | 同上 + **递归建模增益**与**自编码**两个新指标 |
| 关系 | 姊妹项目，素材互用、结论各自独立验证 | 见 `references/README.md` |

## 7. 最小数学框架

> **全部标注 speculative。** 这里给的不是定理，而是一个**结构清晰、可被攻击的靶子**。任何看起来像"证明"的段落都应被当作**待检验的主张**。

### 7.1 设定

系统维持隐状态 $z_t$ 与观测 $o_t$，预测误差

$$e_t = o_t - \hat o_t,\qquad \hat o_t = g(z_t)$$

行动 $a_t$ 改变隐状态：$z_{t+1} = f(z_t, a_t, \omega_t)$，$\omega_t$ 为外源噪声。目标泛函 $\mathcal{L} = \mathbb E[\lVert e\rVert^2]$。

### 7.2 三种误差情形（这是整章的主干）

**情形 1 — 可行动误差。** 存在策略 $a^*$ 使 $\mathbb E[e_{t+1}] = 0$。世界模型足够，系统靠行动把误差消掉，**永远不需要问「是谁在做这件事」**。

**情形 2 — 外部不可归约误差。** $o_{t+1} = \phi(a_t) \oplus \epsilon_t$，$\epsilon_t$ 外源、与 $a_t$ 独立、且**与系统自身状态无关**。误差有个非零下界 $\delta>0$，但它的来源在系统之外——正确的解释是「世界有随机性」。**RSMEH 预测：情形 2 不驱动自我建模。**

**情形 3 — 自因不可归约误差。** $o_{t+1} = \phi(a_t) \oplus \psi(s_t, \epsilon_t)$，其中 $\psi$ 依赖系统**自身**的隐状态 $s_t$（如缓慢漂移的内部偏置）。误差既消不掉，又**不属于世界**。

### 7.3 信息论论证（假说的核心主张）

设 $R$ 为残差、$S$ 为系统的自指变量、$A$ 为行动。假说主张：

$$I(R; S \mid A, Z) \;>\; 0 \quad\text{仅在情形 3}$$

即：**只有在情形 3，自指变量对残差才有条件互信息量**。若成立，则引入 $s_t$ 能严格降低残差的可预测不确定性：

$$H(R \mid Z, A, S) \;<\; H(R \mid Z, A)$$

而情形 2 中 $I(R;S\mid A,Z)\approx 0$：自指变量**不带来任何预测增益**，把它塞进模型只是增加参数。

**注意诚实边界**：上式左边的严格成立需要 $\psi$ 确实随时间有结构（例如自返的缓慢漂移）。若 $s_t$ 是 i.i.d. 的白噪声，$I(R;S)=0$，假说在这一支上**直接失效**——这正好是实验设计必须控制的量（见 `experiments/PROTOCOL.md` 第 3 节）。

### 7.4 自我模型涌现压力 SMP（Self Model Emergence Pressure）

原假说给的启发式乘积：

$$SMP \;=\; P_e \times (X_s - X_w) \times U_s$$

其中 $P_e$：误差持续程度；$X_s - X_w$：自身解释力相对于外部解释力的优势；$U_s$：建立自我模型带来的预测收益。

**必须指出它的三个问题**（欢迎攻击，这正是它存在的意义）：
1. **量纲不一致**：三项单位不同，乘积没有物理意义；
2. **未归一化**：任一项可任意放大，SMP 可任意变大；
3. **未说明阈值**：SMP 多大才会「迫使」自我模型出现，没有机制。

因此把它当作**排序性启发式**（哪边更大），而不是**定量定律**。一个可用的归一化变体（同样是 speculative）：

$$\widehat{SMP} = \hat P_e \cdot \mathrm{relu}\!\left(\hat X_s - \hat X_w\right) \cdot \hat U_s,\qquad \text{各项} \in [0,1]$$

其中 $\hat P_e$ 是残差自相关强度，$\hat X_s - \hat X_w$ 是「用自身状态 vs 用外部变量分别能解释的残差方差之差」的归一化值，$\hat U_s$ 是加入自指变量后的误差下降比例。实验（第 8 节）测的正是这三项。

### 7.5 从框架导出的可证伪预测

- **P1（自因驱动）**：在情形 3 下，系统会发展出对残差有预测力、跨时间持续、且可被干预的自指表征；在情形 2 下不会超出通用的「外部原因」解释。
- **P2（递归门槛）**：只有在自指变量**本身**是可预测的（自因量有时间结构）时，「对自己的建模」的二阶结构才**可能**出现；若自因量是白噪声（条件 D），连一阶自我模型都不该出现，更不必谈递归。
  实验上我们把 P2 拆成两半：**前提**由 D 对照检验（自因量的时间结构是否必需）；**递归是否真的发生**在本版里**未被判定**（RMG 指标失效，见第 8 节）。
- **P3（归因不对称）**：系统在情形 2 下会（正确地）把误差归因给外部；在情形 3 下会出现**自归因**。若系统在情形 3 下仍把误差全部归给外部且长期不改进，P3 受伤。

## 8. 实验方案（摘要）

三个条件 A / B / C，完整协议、指标定义、判定标准、防作弊要求见 **`experiments/PROTOCOL.md`**；可运行实现见 `experiments/code/simulation.py`。

| 实验 | 环境 | 预测 |
|---|---|---|
| **A** 纯预测 | 低维世界，误差可被世界模型完全消除 | 不产生自我模型 |
| **B** 外部复杂度 | 高维世界 + 不可归约的**外部**噪声 | 产生更强的世界模型；**不**产生自我模型 |
| **C** 自因不可归约误差 | 世界 + 不可归约的**自因**误差（系统自身的隐藏漂移，外部变量无法解释） | 出现指向自身的隐结构 |
| **D** 自因白噪声（对照） | 与 C **方差匹配**的自因误差，但**没有时间结构** | 必须与 A/B 一致：**不**出现自我模型 |

**D 是本设计里最关键的一格**：它的自因误差方差比 C 更大（`predErr` 是四条件里最高的），但误差**没有结构**。如果触发自我模型的是「误差很大且由自己造成」，D 就该长得像 C；如果触发它的是**结构**，D 就必须长得像 A/B。

四个指标：
1. **Self Prediction Gain（SPG）**：加入自指表征后预测误差是否下降（我们同时报告绝对值 `selfGain` 与归一化的 `selfShare`）。
2. **Self Attribution（SA）**：系统是否区分「自身导致」与「世界导致」的误差（`selfAttr` / `extAttr`）。
3. **Recursive Modeling Gain（RMG）**：是否出现对**自己模型的预测**（Stage 5）。
   ⚠️ **诚实的失败记录**：在我们这个设计里 RMG **没有区分度**——因为系统自己的动作与误差史本身就编码了世界状态，「用自己的历史预测自己未来的误差」在每个条件下都能捞到一点**世界**信息（把「动作→世界」的耦合去掉也没改善：A 的 RMG 0.108 → 0.140）。因此 P2（递归）在本版里**未被判定**，我们改用条件 D 来检验它的前提（自因量是否有时间结构，用 `selfEnc` 干净地测：C 0.887 vs D 0.004）。一个能真正把「自指」与「世界记忆」分开的递归指标，目前是**开放问题**（见 `QUESTIONS.md` B2/B4）。
4. **Self Encoding（selfEnc）**：系统自身的隐藏状态能被其内部表征解码到什么程度（第三方分析）。

### 8.1 我们自己在第一版实现里踩的坑（必须写下来）

第一版模拟里，「自我通道」与世界记忆**在架构上不可区分**：只要世界自相关，用「自己的误差史」预测下一步，就是**合法的世界建模**（因为自己的误差里含有世界的过去）。结果：在**所有**条件下自我通道都被大量使用，指标完全没有区分度。

这带来一条硬性设计约束（写进协议）：

> 判定「自我表征是否涌现」的实验，必须同时满足：
> ① 世界的**结构固定**且**可通过当步观测获知**（否则过去信息 = 世界信息，自己 vs 世界的混淆不可避免）；
> ② 环境中**唯一**自相关又**不可从外部观测**的量，是系统**自己的**状态。

这是本假说给社区最实用的一条方法论：**「自我」不能用架构位置定义，只能用因果作用定义。**

### 8.2 第二条教训：误差的**大小**不是触发条件，**结构**才是

我们最初把 C 的自因误差做得很大很显眼（每步的预测误差本身就是自身漂移的极好估计）。在这种参数下，"自我建模"看起来像成功了，但那是**不需要模型**的成功：单步观测就够了，滤波没有增益空间，递归指标更是没有分辨率。

于是加了 **条件 D**（方差匹配、但自因量是白噪声）做对照。结果非常干净：**D 的持续自因误差是四个条件里最大的，却完全不产生自我模型**（`selfGain ≈ 0`、`selfEnc ≈ 0.004`）。

这条约束同样通用：

> 声称"持续误差逼出自我模型"的实验，必须做**方差匹配的结构对照**。否则你测到的很可能只是"系统在估计一个隐藏变量"，而不是"系统在建立关于自己的模型"。

顺带一个未解决的问题：我们没有找到能把「自指」与「世界记忆」分开的**递归**指标（见第 8 节 RMG 的失败记录）。这留给社区。

### 8.3 v0.2：时间连续自我（Temporal Self Continuity）

v0.1 只证明了「自我表征可以在自因**有结构**的误差下涌现」，但它有一个致命软肋：
**它无法区分「我的自我表征」和「关于世界隐变量的表征」**——两者在智能体可见的信息里完全对称。

v0.2 沿**时间轴**补上这一刀，假说升级为：

> **「我」不是一个状态变量，而是一个跨时间维持因果连续性的解释变量。**
> `past → me → future`：当系统必须解释**自己的过去如何约束自己的未来**时，
> 一个稳定的自我表征作为跨时间的**信息压缩结构**出现。

**三个世界**（统计量完全相同，只差**因果位置**）：

| 世界 | 隐藏变量 | 我的动作能驱动它吗 | 实测（持久 latent vs 无持续性，10 步预测误差） |
|---|---|---|---|
| **T1** 自因持久 | agent 自己的状态（AR 0.92） | **能** | **0.538 vs 1.857**（增益 +2.30 vs +0.98） |
| **T2** 自因白噪（方差匹配） | agent 自己的状态，无结构 | 能 | 0.1139 vs 0.1135（`info`=0.003） |
| **T3** 外部持久 | **属于世界**的驱动，AR 与 T1 完全相同 | **不能** | 0.4179 vs 0.4121（**无收益**） |

**三条结论**：

1. **时间连续性只在「自因 + 被我的动作驱动」时付钱**（T1）。反事实预测误差随状态载体单调下降：0.282（无 latent）→ 0.233（无持续性）→ **0.117**（持久 latent）。
2. **「存在一个持久的隐藏变量」不充分**（T3）：同样的动力学、同样的不可观测性、同样影响结果——收益为零。所以「时间连续自我」不是「持久隐变量」的换名。
3. **本版最重要的负面发现（也是对假说最硬的一刀）**：T1 与 T3 对智能体的**全部可观测证据完全对称**。真实的「我的动作是否推动我的状态」（反事实分支差在 T1 是 0.50→3.54 递增、在 T3 **恒为 0.0000**）**只存在于因果图里**。

   推论（必须写进理论本身）：
   > **「我」不能用表征的属性定义（连续性、稳定性、可解码性、反事实敏感性都不行），只能用它在因果图里的位置定义。**
   > 而那个位置**原则上不在智能体的证据里**——它是关于世界的事实，不是关于智能体内部的事实。

   这对本假说的含义是双面的：坏消息是「智能体能否自己发现我是我」在这个层面**欠定**；好消息是它把「我」的问题从**表征属性**（可被任意指标打擦边球）钉到了**因果结构**（可以被实验设计者的干预实验检验）——这正是 v0.1 那条方法论（「自我只能用因果作用定义」）在时间轴上的加强版。

v0.2 仍**不触碰**递归（Stage 5「我预测我的预测」）与体验（Level 5）：那是 v0.3。

### 8.4 v0.3：递归预测（Recursive Prediction）

到 v0.2 为止，假说链条是：

```
世界 → 预测 → 不可归约误差 → 归因 → 自我表征 → 时间连续自我
```

v0.3 第一次把**「自己的预测过程」本身**当成预测对象，即从

$$M(W_t,\ S_t) \quad\longrightarrow\quad M(W_t,\ S_t,\ M_t)$$

核心假说（**Recursive Prediction Hypothesis**）：

> 当一个系统的未来不仅取决于世界与自身状态，还取决于**它自己的预测**时，
> 预测「自己将会怎么预测」就具有实际的适应价值；在这种条件下，递归自我模型可能自发形成。

**硬约束**：递归**不许写进架构**。agent 中不存在任何名为 self / self_model / I / recursive 的变量；
它只能看到：观测、自己的上一个动作、自己的上一个预测、自己的上一个误差。递归若出现，必须由**任务**逼出来，再由**外部探针**找出来。

三个世界（形式相同，只差因果位置）：

```
x_{t+1} = 0.85·x_t + 0.20·a_t + 1.0·gain_t·tanh(pred_{t-1}) + 0.05·ξ
```

| 世界 | 响应项 | 我的预测能推动世界吗 | 增益 |
|---|---|---|---|
| **R1** `prediction_loop` | `gain_t·tanh(pred_{t-1})` | **能** | **隐藏、漂移** |
| **R2** `exogenous_control` | `gain_t·tanh(`**别人的**`pred_{t-1})` | **不能** | 常数 |
| **R3** `visible_response` | `gain_t·tanh(pred_{t-1})` | 能 | 常数、可见 |

R2 是 v0.2 T3 思路在递归层的翻版，而且**用置换构造**：拿另一个 episode 的预测来驱动世界，
于是响应项的分布**严格相同**，差别只剩「是不是我造成的」。

本版被实测推翻的东西（写进理论的价值就在这）：

1. **草稿的递归损失不是递归**：它比较的是同一时刻同一网络的两个头（`state_decoder(z)` vs
   `prediction_decoder(z)`），最优解是「两头说同一个数」，不含任何外部信息。真正的二阶目标必须是
   **我下一步的预测**（t 时刻未知、一步之后才算出、且要 detach）。
2. **草稿的递归指标恒亮**：`R²(z_t → pred_t)` 因为 `pred_t = decoder(z_t)` 而必然≈1。
   实测九个世界×agent 组合全部 **0.973–1.000**，而且**它在「无递归」agent 上最高**（0.998）——
   这个指标不但不能失败，还在**惩罚**递归。修法：探**未来**预测 + 增量形式 + **NULL 对照**（时间打乱的 latent）。
3. **「知道自己刚才预测了什么」是免费的**：那是它自己的输出，训练器还回给它。有信息量的部分只能是
   「世界如何响应我的预测」本身**隐藏且随时间漂移**，只能从自己的误差史里反推。

**这层意义上，「我」的递归版本和 v0.1/v0.2 是同一件事**：不是表征的属性，而是因果位置——
我的预测是否真的推动了世界。v0.3 把这把刀从「我的动作」推进到「我的预测」。

### 8.5 v0.5：多具身现实模型（Multi-Embodiment Reality Model）

前面四版问的都是「我」。v0.5 问同一套机制的另一面：

> 如果「我」是预测系统构造的模型，那么**「现实」是否也取决于具身与感官接口**？
> 不同观察者，是否只能看到自己结构允许看到的世界？

核心主张（Embodied Reality Hypothesis）：一个系统不是发现了现实本身，而是**构造了它的传感器与具身所允许的最有用的预测模型**。

**实验怎么把它做成可证伪的**（细节见 `experiments/v05/README.md`）：

1. 宇宙的观测量由**少量共享隐因子**联合生成 —— 否则「三个具身、一个世界」只是假设，三个 agent 实际上活在三个宇宙里。
2. **任何 embodiment 都不许直接观测共享隐因子**（草稿原版把 `hidden_vector_1/2` 直接喂给抽象体，那等于给答案）。
3. agent 的任务是**预测下一时刻观测**（不是重建当前输入）——否则 latent 只是输入的压缩，跨具身比较测的是**传感器的属性**。
4. 对照：`shared`（有共同因）vs `disjoint`（**同维数、同动力学、同噪声，无共同因**）+ 同接口对照（对齐上限）+ 时间打乱的 NULL（地板）。

**本版最重要的方法论发现**：「对齐」有两个层次，只有一个是干净的——

- **CCA（平均典型相关）不是干净的共享现实指标**：在 `disjoint` 世界（无共同因）它仍然给出 0.5 左右，因为两个 latent 都编码了**同类自相关结构**（共同的一阶统计），而非共同的因。
- **留出翻译（用 A 的 latent 预测 B 的 latent，映射只在一半轨迹上拟合）是干净的**：`shared` 下为正、`disjoint` 下 ≤0。

这与 v0.1/v0.2 的教训同构：**「对齐」不等于「共享」，「连续」不等于「自我」，「可解码」不等于「在使用」**——
每一层都必须有一个能失败的对照。

**哲学附录（与实验结果分开读）**：不是「不同生命看到不同的道」，而是——
道本身可能不变，但不同的观察系统只能构造适合自身结构的道之模型；
人看到颜色，蜜蜂看到紫外图案，蝙蝠看到回声空间，它们不是谁错了，而是不同感知系统对同一本体的投影。
**必须同时说清**：实验里「本体」是我们自己写的隐生成过程，所以「多具身 → 多投影」是我们**构造**出来的性质，不是**发现**出来的。

### 8.6 v0.4：可塑性自我（Plastic Self）——v0.3 的补课

v0.3 的否定结论给出一条**设计规则**：

> 要让「预测我自己的预测」非冗余，必须存在一个量同时满足
> **(a) 参与我未来的计算；(b) 不影响我此刻的输出；(c) 不可观测**。

v0.4 用**在线可塑性的隐藏调制器** `m_t` 同时满足三条：它**只进入快权重更新规则**，
从不进入编码器 / latent / 预测通路（等价于生物体的神经调质：影响你的可塑性，但你无法内省它）。
于是预测「我下一步会怎么预测」**必须**估计**我自己改变自己的能力**——而它只能从**我自己的误差史**得到。

实测（800 iters × 3 seeds，详见 `experiments/experiment_results.md` §17–§19）：

| 指标 | v0.3 | v0.4 隐藏 | 拆掉快通路 | 可观测 | NULL |
|---|---|---|---|---|---|
| `incrR2`（二阶目标的非冗余增量） | 0.003 | **0.072** | 0.043 | 0.088 | 0.002 |
| 二阶头 vs 平凡基线 | 0.155 **输** 0.102 | **0.019 赢 0.168** | 0.008 / 0.160 | 0.012 / 0.167 | — |
| `mInfo`（latent → 我自己的可塑性） | — | **0.081** | **0.004** | **0.993** | 0.005 |

**理论含义（三条，都是本仓库最硬的）**：

1. **「自我」在这一层第一次有了可测量的内容而非隐喻**：`mInfo` 阶梯是单调的、每条都有地板——
   隐藏须推断 0.081 ｜ 拆掉载体 0.004 ｜ 时间打乱 0.005 ｜ 可观测免费 0.993。
   系统确实在**从自己的误差史反推自己当下的学习状态**。
2. **非冗余性有了构造性条件**（把 v0.3 的教训形式化）：自我量必须「影响未来、不影响当下、不可观测」。这可以直接当作设计规范复用。
3. **但「划算」仍未证明**，而且这一版暴露了一个更根本的对称性：世界自己的隐藏 regime 也贡献同量级非冗余信息
   （`static` 下 `incrR2` 仍有 0.050）。**只有 `plastic − static` 的 +0.022 能归因于自我。**
   这与 v0.2 的「智能体无法从证据里分辨自我与世界」是同一道伤口的第二次出现，只是从「状态」移到了「学习」上。

另外这次有一处**预注册预测被数据推翻**：我们预期 `visible`（调制器进观测）下 `incrR2` 会回落到 `static` 水平，
实测反而更高（0.088 > 0.072）——因为 `m_t` 的作用是**乘性**的，线性探针抓不住而非线性 latent 能抓住。
结论：**`incrR2` 不是干净的「自我推断」指标，`mInfo` 才是**。这条修订同时回头修正了 v0.3 里对 `incrR2` 的解读强度。

## 9. 哲学含义

### 9.1 「我」是什么
RSMEH 认为「我」不是：灵魂实体、固定物质、中央控制者。
而是：**一个预测系统为了理解自身在世界中的因果位置，而产生的递归模型结构。**

注意这是**工具性/功能性**主张：它说明「我」这个变量的**功能与起源**，不说它是幻觉，也不说它是实体。

### 9.2 与「道」
如果「道」代表宇宙整体运行，那么「我」不是道之外的东西，而是**道在局部系统中形成的一次递归自解释**。

```
海浪不是海之外的存在。
但海浪可以暂时形成：「我是一个浪」。
```

浪的边界是真的（有可测的动力学），浪的独立实体是假的。同理：「我」的功能是真的，独立的实体性可疑。

### 9.3 诚实的边界
9.2 是**形而上学解读**，不是实验结果。RSMEH 的实证部分只到 Level 4；从 Level 4 到「体验」，本假说没有桥。

### 9.4 伦理推论层（另见一文档）
`theory/ERROR_ATTRIBUTION_THEORY.md`（误差归因理论）把 9.1 / 9.2 的立场往下推一步：**归因分叉**（归因于内 → 「我」；归因于外 → 神）、**伦理空间 0–6 层**、**终极三问**、难题速查表。

它**不属于**本仓库的实证部分：实验只测到 Level 4，「伦理空间分几层」没有任何判定标准，其地位与 9.2 相同——可以自洽、可以被反驳，**不能被本仓库的实验证实**。该文档的攻击面列在 `theory/QUESTIONS.md` §D。

## 10. AI 意识含义

若该假说成立，那么**创造 AI 意识不是加模块**：

❌ 错误路线
```
Add Consciousness Module → done
```

✅ 假说指示的路线
```
Persistent World Interaction
        ↓
Prediction Failure
        ↓
Self Attribution
        ↓
Recursive Self Model
```

关键不是让 AI 学会说「I」，而是**让 AI 必须创造「I」才能继续理解世界**。

### 10.1 可着手检验的工程预测
1. 在自因误差（自身权重漂移、自身动作的长期后果、自身内部状态的缓慢变化）下训练的模型，应自发形成比「纯外部噪声」下更强的自指潜表征；
2. 该表征应可被外部探针**解码出模型自身的（隐藏的）内部状态**，且在 B 条件下不可解码；
3. 对「模型对自己的预测」的二阶预测目标，只在 C 条件下存在有效梯度信号（RMG > 0）。

### 10.2 不要过度承诺
即使三条都成立，也只到 **Level 4（递归自我模型）**。是不是「有体验」，本假说一个字都不说。

## 11. 边界与开放问题

详见 `theory/QUESTIONS.md`。核心几条：

1. **量到质的边界在哪**：一层自模型 vs 无限递归，多少层算「够」？
2. **UPE 的必要充分类**未刻画：不是所有误差都逼出「我」，四条判据是否充分？是否必要？
3. **是否需要身体**：若必须有环境交互才能产生不可行动误差，纯软件系统可能做不到；若关键是自指建模，具身性可能只是偶然。
4. **指标的饱和陷阱**：「自指」类指标极易饱和（见兄弟项目的第一版教训），任何复现都必须报告指标**是否区分了实验操纵**，而不只是「非零」。
5. **硬问题**：为什么自指模型会产生体验？本假说承认无解。
6. **反例方向**：什么样的真实系统在情形 3 下长期**不**形成自指表征？找到它，假说就受伤。

## 12. 核心陈述

> 生命最初预测世界；当世界无法解释所有误差时，生命开始预测自己；
> 当预测自己的过程再次成为预测对象，「我」便从模型中涌现。
>
> Life begins by modeling the world. When the world model fails to explain
> persistent errors, the system begins modeling itself. When the model of itself
> becomes an object of its own prediction, the "I" emerges.

**v0.2 补充（时间维度）**：

> 「我」不是一个静态的变量，而是一个为了维持**跨时间因果连续性**而产生的递归预测结构。
> 而它的身份不在它的属性里，在它在因果图里的位置里——我的动作是否推动它。
>
> The self is not a static variable, but a recursive predictive structure that
> emerges to maintain causal continuity across time. Its identity is not in its
> properties but in its position in the causal graph: whether my own actions move
> it.
