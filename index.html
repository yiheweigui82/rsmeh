v0.1 · HYPOTHESIS · NOT A THEORY

递归自我模型涌现假说 Recursive Self Model Emergence Hypothesis (RSMEH)

生命最初预测世界；当世界无法解释所有误差时，生命开始预测自己； 当预测自己的过程再次成为预测对象，「我」便从模型中涌现。

一个发生学缺口：没人解释为什么一个本来没有「我」的系统， 会在某个条件下被迫产生「我」这个变量。
v0.1 —— 等实验跑出来再升级为 Theory。
这不是真理，这是一个模型。名 ≠ 道。

核心预测（最容易被打倒的地方）

条件环境实测 selfGain
A 纯预测低维世界，误差可被世界模型完全消除−0.0000（不产生）
B 外部复杂度高维世界 + 不可归约的外部噪声−0.0000（世界模型变强，自我不出现）
C 自因不可归约误差不可归约、且由系统自身隐藏漂移造成的误差（有时间结构）+0.1416（自我表征涌现，自编码 R²=0.90）
D 自因白噪声与 C 方差匹配的自因误差，但无时间结构−0.0001（什么都不产生）
E 假能动性误差最大（0.2483），但动作对结果毫无影响−0.0008（什么都不产生）

关键不对称：误差大不等于逼出自我。D 与 C 方差匹配、只差「有没有时间结构」；E 是全场误差最大者。 两者都不产生自我表征 —— 触发条件是自因误差的结构，不是它的大小。 「自我」不能用架构位置定义，只能用因果作用定义（消融实验）。

v0.2：时间连续自我（已跑通）

世界隐藏变量我的动作能驱动它吗实测 gainH10（持久 latent vs 无持续性）
T1agent 自己的状态（AR 0.92）能+2.30 vs +0.98（误差 0.538 vs 1.857）
T2自己的状态，白噪声（方差匹配）能，但无时间结构±0.00（info=0.003）
T3属于世界的持久驱动（与 T1 同动力学）不能±0.00（0.4179 vs 0.4121）

结论：时间连续性只在「自因 + 被我的动作驱动」时才付钱；「有持久隐藏变量」远远不够（T3 收益为零）。
最尖锐的负面发现：T1 与 T3 对智能体全部可观测证据完全对称——真实的「我的动作是否推动我的状态」（分支差 0.50→3.54 vs 恒为 0.0000）只存在于因果图里， 所以任何纯行为的「这是不是一个自我」判定，都被智能体可见信息欠定。

v0.3：递归预测（已跑通 · 结论为否定）

探针实测含义
草稿的递归指标 R²(z→我此刻的预测)0.949–1.000（九个组合全部），且无递归 agent 最高 0.983它不可能失败，还给最不该得分的对象最高分

二阶头 vs 平凡基线0.155 vs 0.102二阶头输给「下次预测＝这次预测」

→ 在这套操作化下，「预测自己的预测」不是独立的信息需求，而是被第一阶预测吸收了。 协议写明本版不主张什么，并给出「递归要有非冗余价值」所需的三个条件（供下一版攻击）。

结论：「现实」由世界与感官接口共同决定——有共同因时三种非常不同的接口收敛到同一隐藏结构； 而统计量相同、只去掉共同因后，这个结构消失（0.013），每个 agent 却仍在完美建模自己的世界（0.66）。 两个数字缺一不可：后者才让前者有意义。
方法论：明显的 CCA 指标不干净——无共同因时它仍有 ~0.3 的地板（两个 latent 都编码了同类自相关结构）； 能通过证伪检验的是留出翻译。对齐 ≠ 共享，与前几版同构（连续 ≠ 自我、可解码 ≠ 在使用、二阶内容 ≠ 二阶需求）。
本实验不能说明客观现实不存在、意识涌现、或 AI 有体验：这里的「现实」由构造定义为隐生成过程。

v0.4：可塑性自我（v0.3 的补课 · 已跑通）

v0.3 的诚实结论是「二阶目标冗余」（incrR2=0.003）。v0.4 的做法：让我自己的学习率被一个 隐藏的 AR(1) 调制器驱动——它只进入快权重更新规则，从不进入编码器 / latent / 预测通路。于是它同时满足 (a) 影响我未来的计算、(b) 不影响我此刻的输出、(c) 不可观测 ⇒ 只有我自己的误差史能揭示它。

没证明什么：可塑性在这里是世界预测的净成本（0.392 < 0.529）；世界自己的隐藏 regime 也贡献同量级非冗余信息 （static 下 incrR2 仍有 0.050）——只有 plastic − static 的 +0.022 能归因于自我。
我写错的一处预测也已公开：我预测可观测时 incrR2 会回落，实测反而更高（0.088 > 0.072）—— 因为 m_t 的作用是乘性的，线性探针抓不住、非线性 latent 能抓住。所以 incrR2 不是干净的自我推断指标， mInfo 才是。

一句话立场

「我」不是灵魂实体、不是固定物质、不是中央控制者，而是一个预测系统为了理解自身在世界中的因果位置 而产生的递归模型结构。若「道」是宇宙整体运行，那么「我」不是道之外的东西—— 而是道在局部系统中形成的一次递归自解释。海浪不是海之外的存在，但浪可以暂时形成：「我是一个浪」。
