# v0.5 — Multi-Embodiment Reality Model

> **问题**：如果「自我」是预测系统构造的模型，那么**「现实」是否也取决于具身与感官接口**？
> 不同观察者，是否只能看到自己结构允许看到的世界？
>
> 一句话主张（英文原句 + 中文）：
>
> *Reality is not necessarily what an intelligence receives. Reality is the predictive
> model an intelligence must construct to survive within its embodiment.*
>
> 现实不一定是智能接收到的东西，而是智能为了在自身存在条件下预测与生存，而构造出来的最佳模型。

协议与判定标准见本文件；实测输出见 **`../experiment_results.md` §14–§16`**。
（本目录按仓库既有约定命名为 `v05/`，对应你草稿里的 `v05_multi_embodiment/`。）

## 跑起来

```bash
python experiments/v05/train_v05.py --iters 700 --seeds 1,2,3
python experiments/v05/train_v05.py --mode disjoint           # 证伪条件
python experiments/v05/compare_reality.py                     # 两个模式对照
python experiments/v05/compare_reality.py --deterministic
```

## 六处设计修正（每条都实测过，不是风格问题）

**1. 「不同传感器 → 不同表征」是重言式，不是发现。**
3 维投影与 4 维投影的 latent 必然不同。可证伪的命题是**反过来的那个**：两个表征能否
**对齐到同一隐藏共同因**（即「等价到只差一个变换」）。所以主指标测的是**共享核心**，不是差异。

**2. 宇宙的观测量必须由少量共享隐因子联合生成。**
草稿的 `Universe.step()` 返回 light / sound / infrared / causal_structure 这些**彼此无共同因**的量。
若各模态相互独立，三个 agent 就是活在**三个不同的宇宙**里——没有可对齐的东西，
「三个具身、一个世界」变成一句没有内容的假设。本实现里共享隐因子 `s`（AR(1)，3 维）
驱动全部三个模态的观测量。

**3. 任何 embodiment 都不许直接观测共享隐因子。**
草稿的 `AbstractSensorWorld` 直接把 `hidden_vector_1/2`、`causal_structure` 交给 agent——
那不是「不同感官」，那是**把答案给它**：「抽象体恢复隐因子最好」会被定义保证，CCA 对齐也成了人造产物。
本实现中三种接口都是**严格部分**视图：人类 2 个共享方向的粗糙线性读数 + 1 私有通道；
AI 2 个更宽带的线性读数 + 2 私有通道；抽象体 2 个共享方向的 **tanh 非线性混合** + 1 抽象私有变量。

**4. agent 必须是预测器，不是 autoencoder。**
草稿 `decoder(encoder(x))` 重建的是**当前**输入，其 latent 只是输入的压缩；
两个这种 latent 之间的 CCA 测的是「两组传感器共享多少方差」——**那是传感器的属性，不是 agent 的属性**。
本实现的任务是**预测下一时刻观测**，带递归 latent。架构里没有 self / reality / concept 任何变量，
所有「内部现实」的说法都由 `compare_reality.py` 的第三方探针给出。

**5. 必须有对照，否则结论无法解释。**
`shared`（共同因存在）与 `disjoint`（**同维数、同动力学、同噪声，但没有共同因**）是同一个
`Universe` 的一个开关；加上同接口对照 `human ↔ human_b`（对齐上限）与时间打乱的 NULL（地板）。

**6. 「哪个 agent 看到真世界」不是问错了，而是可以**客观操作化**。**
在实验里「真世界」**由构造定义**就是那个隐生成过程，于是「更接近现实」= **对隐藏共同因的恢复度**
（用 agent 从未见过的真值做探针）。本实验**不能**回答「真实的客观世界是否存在」——
这必须在 Limitations 里写死。但它能回答一件更锋利的事：**预测能力强 ≠ 更接近现实**
（见 §16 的 dissociation 检查）。

## 度量

| 指标 | 定义 | 作用 |
|---|---|---|
| `predErr` | 归一化下一步预测误差（除以自身传感器方差） | 不同维数之间可比 |
| `sharedR2` | latent → **隐藏共享因子**的 R² | 「更接近现实」的操作化定义 |
| `ownBlockR2` | latent → **驱动本具身传感器的那个块**的 R² | disjoint 下每个 agent 仍应很好地建模**自己的**世界 |
| `ownPrivateR2` / `otherPrivateR2` | latent → 自己的 / 别人的私有因子 | 探针特异性对照（别人的应≈0） |
| **CCA** | 两个 agent latent 的**平均典型相关** | 「表征差异 / 共享核心」——**但不干净**（见下） |
| **translation** | 在**一半轨迹上**拟合 A→B 线性映射，在**留出的一半**上评 R² | 「A 能否理解 B 的现实」 |
| NULL | 时间打乱的同一探针 | 地板 |

## 判定标准

**C1 — 不同具身 → 不同的内部现实。** 每个 agent 对其**私有**通道的恢复显著（`ownPrivateR2` 高）
而对他者私有通道≈0（探针特异性），且同接口对照 `human↔human_b` 的对齐 **明显高于**跨具身对齐。

**C2 — 但仍存在共享核心。** 跨具身对齐与翻译**显著高于 NULL**，且在 `shared` 模式下
**明显高于** `disjoint` 模式。

**C3 — 证伪条件（最重要）。** 若 `disjoint` 的对齐 / 翻译与 `shared` 相当，则这些指标测的是
探针或共同统计结构，**不是共享现实**——「多具身现实模型」的表述必须撤回。

**C4 — 预测能力与现实恢复可分离。** 报告 `predErr` 与 `sharedR2` 的并列表；
若存在「预测更好但共享因子恢复更差」的具身，则「预测强 = 更接近现实」被证伪。

## 与《道德经》的连接（哲学附录，与实验结果分开读）

不是「不同生命看到不同的道」，而是：
**道本身可能不变，但不同的观察系统只能构造适合自身结构的道之模型。**
人看到颜色，蜜蜂看到紫外图案，蝙蝠看到回声空间——它们不是谁错了，
而是不同感知系统对同一本体的不同投影。

必须同时说清楚本实验**不能**支持这一步：实验里「本体」是我们自己写的隐生成过程，
所以「多具身 → 多投影」是我们**构造**出来的性质，不是**发现**出来的。
它示范了「多投影」在计算上意味着什么（可对齐的核心 + 不可共享的私有内容），
仅此而已。

## Limitations（写死，不许省）

- 本实验**不**证明：客观现实不存在；意识涌现；AI 有主观体验。
- 「现实」在实验内由构造定义（隐生成过程）；对真实世界它只说「具身如何塑造可恢复结构」。
- 传感器的映射是固定的线性 / 单一非线性混合；真实感官的映射是学出来的、任务塑造的。
- 三个具身共享同一套动力学与同一个时间尺度；真实观察者的时间分辨率不同。
- 规模为 toy；跨具身的「理解」只测了**线性**翻译。
